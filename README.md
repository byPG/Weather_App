# Weather_App
Weather application using Open-Meteo API, built with HTML, CSS and JavaScript.

# About the Weather App
The app allows users to search for a city and check the current weather data.

# Features
- search weather by city name
- display current temperature
- display weather description
- display wind speed
- error handling for empty input or city not found
- responsive layout

# Technologies
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Open-Meteo API
